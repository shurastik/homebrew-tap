# shurastik/homebrew-tap

Homebrew formulae for [agterm-kit](https://github.com/shurastik/agterm-kit).

```bash
brew install shurastik/tap/agk
agk setup   # link the agent skills; rerun after every `brew upgrade agk`
```

`Formula/agk.rb` is rendered by `scripts/release.sh` in agterm-kit; do not edit it here.
